Compilation Instructions:
=========================

Method 1: Using Overleaf (Recommended)
---------------------------------------
1. Go to https://overleaf.com
2. Create New Project → Upload Project
3. Upload this ZIP file
4. Click "Recompile"
5. Download PDF

Method 2: Local Compilation (requires LaTeX installation)
----------------------------------------------------------
Run these commands in order:
    pdflatex term_paper.tex
    bibtex term_paper
    pdflatex term_paper.tex
    pdflatex term_paper.tex
